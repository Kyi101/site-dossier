# Your Site Dossier references

This folder contains saved website references, visual captures, and the owner's
notes. Start with the [reading skill](.site-dossier/skills/use-site-dossier-v2/SKILL.md)
for the file layout, preference fields, and older capture formats.

To use this folder with an agent, give it the folder path and say:

> Read SITE-DOSSIER.md and its linked skill. Use my notes and selected aspects
> to understand what I like. Cite the captures behind your suggestions and
> distinguish my preferences from your own observations.

For a specific project, also name the project, reference folders, or websites
you want it to use. Saved references alone do not mean you like every part.

The skill is a portable Markdown file. It is not automatically installed or
discovered by every agent. You can point directly to the linked SKILL.md when
working inside one capture folder.

Site Dossier creates this guide and the versioned skill when saving a capture.
It preserves your edits; an unchanged entry from an older release can be
updated to link to the latest reader. Versioned skills and older captures are
left as they are. No collection index is required: an agent can find small
note.md and meta.json files first, then inspect the relevant visuals.

New page captures include readable page tiles and timestamped video frames
when available. Selection captures contain individual crops, a context image,
item notes, and sampled structure/styles for picked elements. The reader
explains the file paths and limits for both.
