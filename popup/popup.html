Quick guide

Auto

The default for regular pages. Scrolls, records video, and takes screenshots together. Stops at the bottom or at the 3-minute limit, then saves.

Manual

For menus, animations, and other interactions you want to record yourself. You control the page until you press Stop or reach the 3-minute limit.

After Stop, the page scrolls once automatically for screenshots, then returns to your position. The video has already stopped.

Selection

Click to select an element. Hold Ctrl (Windows/Linux) or Cmd (Mac) while clicking to add or remove elements, up to eight. Choose Elements or Rectangle in the extension popup before opening the picker. Drag the panel by its heading if it covers a detail.

Add an optional note for each item, then Save. The picker stays open so you can select and save another set. Close it or press Escape when finished. Your popup notes and taste choices apply to the capture as a whole. Escape cancels. Selections must fit inside the visible page; use Page capture for longer sections. Browser zoom is supported; reset pinch zoom before selecting.

Selected browser animations are held until you save, deselect, or close. Selections save sharp crops, a context image, coordinates, and sampled structure/styles for picked elements. The picker is hidden from the images. A rectangle saves visual evidence only; neither tool exports a ready-to-use component.

Stop and saving

Use Stop on the camera control or Stop recording in this popup. Keep the captured tab active until Saved appears. Saving can take a little while; a failed save shows an error.

Choose a folder

Choose opens the folder dialog directly. Select one library folder for all capture modes and allow access. Website captures and collected images share this setting; their files are organized automatically. On Windows, use a subfolder such as Desktop\Site Dossier. Chrome may block system folders or ask for access again after a browser restart.

What gets saved

Page captures save a full-page JPEG, readable page tiles, video, timestamped stills and a contact sheet when decoding succeeds, HTML, and sampled design tokens. Your taste selections, notes, and context stay with each capture. Files stay in your chosen folder.

Capture the same page again on any day to add to its existing folder. Auto, Manual and selections each save separately inside it. The folder keeps its original name; earlier captures are preserved.

The camera control stays visible and appears in the JPEG and video. The HTML snapshot is a reference, not a guaranteed offline copy.

Share your taste with an agent

Select only the aspects you like. Leave everything blank to save a reference without a preference. Use the note to describe what to reuse or avoid. Tags can describe patterns such as scroll-driven or storytelling, or organize references by project.

Your form is remembered locally for each page, including after a capture, closing this popup or switching tabs. Reopen it for a Manual pass or selections without filling it again. You can edit the fields for the next pass; other pages have separate forms.

Give your agent the save folder to explore. SITE-DOSSIER.md provides a visible starting point. It links to a reading skill that also explains older captures. Existing guide files are preserved; the skill is not installed into your agent automatically.

Appearance

The popup follows your system theme automatically.
