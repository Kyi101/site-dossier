# Privacy policy for Site Dossier

Site Dossier saves a visual reference of a page only after you click **Start auto capture** or **Start manual recording**. During that capture it processes the page URL, visible tab video and screenshots, DOM and computed styles, page-linked CSS and JavaScript, and any note or tags you enter. It writes the resulting files to the local folder you select.

The extension does not upload captured files or send them to a server operated by the developer. It does not use analytics or advertising. To build the HTML snapshot, the browser may request CSS and JavaScript URLs linked by the page. The extension stores your selected folder handle in browser storage so you can use the same folder again; it keeps capture details in temporary session storage until the capture finishes.

The extension does not control what happens to files after they are saved. If you choose a folder synced by OneDrive, Dropbox, or another service, that service may upload the files under your own account and settings. You can inspect or delete captures in the selected folder and change the output folder from the extension popup. Removing the extension clears its browser-stored folder selection.

A capture may contain private or sensitive material visible on the page. Capture only pages you intend to save. Saved HTML may contain the source site's scripts or links; inspect it in a code editor.

For questions, contact hlib@kyii.studio. The extension itself does not collect a developer-held copy of your captures.
